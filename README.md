# 🛡️ Zemory Family Guard — التحكم في أجهزة العائلة

نظام خاص للتحكم في هواتف وتابلات وتلفازات **أندرويد** في البيت، من تطبيق للوالد أو من لوحة ويب.

| الميزة | كيف تعمل |
|---|---|
| ⏳ وقت الاستخدام لكل تطبيق | حد يومي بالدقائق لكل تطبيق؛ عند انتهائه يتوقف التطبيق حتى منتصف الليل |
| 🌙 وقت النوم / إيقاف الكل | جدول يومي يوقف التطبيقات، وزر «إيقاف كل التطبيقات الآن» |
| 🕒 جدول الشاشة الأسبوعي | لكل يوم وقت فتح الشاشة (من – إلى)؛ بعد انتهائه إما قفل الشاشة بالكامل أو تعمل التطبيقات المسموحة فقط |
| 📨 طلبات الطفل | يطلب الطفل فتح موقع أو تطبيق محظور؛ يوافق المالك مؤقتاً أو دائماً أو يرفض |
| 🗑️ حذف وتثبيت التطبيقات | حذف صامت، إخفاء تطبيقات النظام، إعادة تثبيتها، وتثبيت APK من رابط |
| 🔒 قفل التطبيقات | حظر كامل، أو قفل برمز المالك (PIN)، أو قفل تطبيق الإعدادات |
| ⚙️ إعدادات الجهاز | منع التثبيت/الحذف، إعادة ضبط المصنع، تغيير الوقت، Wi-Fi، الكاميرا، لقطات الشاشة… |
| 🌐 المواقع | سجل كامل بالنطاقات (لكل التطبيقات) والصفحات (في المتصفحات)، مع الحظر والبحث الآمن |
| 📺 التلفاز | نفس التطبيق يعمل على Android TV / Google TV |

## مكونات المشروع

```
child/      تطبيق الأجهزة (يُثبَّت على هاتف/تابلت/تلفاز الطفل) — Kotlin
parent/     تطبيق الوالد (يحمل لوحة التحكم داخله)
web/        لوحة التحكم (HTML/JS) — نفسها في تطبيق الوالد وعلى الويب
scripts/    سكربت إعداد الجهاز عبر adb (Linux/macOS و Windows)
firestore.rules   قواعد الأمان: كل جهاز لا يراه إلا حساب والده
.github/workflows/build.yml   البناء التلقائي عبر GitHub Actions
```

الاتصال بين الوالد والأجهزة عبر **Firebase** (الخطة المجانية Spark تكفي):
Authentication (بريد وكلمة مرور) + Cloud Firestore.

---

## 1) إعداد Firebase (مرة واحدة، ~10 دقائق)

1. افتح <https://console.firebase.google.com> ← **Add project** (يمكن تعطيل Analytics).
2. **Build ← Authentication ← Get started ← Email/Password ← Enable**.
3. **Build ← Firestore Database ← Create database** (اختر أقرب منطقة، ثم Production mode).
4. في Firestore ← تبويب **Rules**: الصق محتوى ملف [`firestore.rules`](firestore.rules) واضغط **Publish**.
5. **Project settings ← Your apps ← Android**: اسم الحزمة `com.familyguard.child` ← سجّل ← نزّل ملف `google-services.json`.
6. (مستحسن) في نفس الصفحة أضف تطبيق **Web** وانسخ كائن `firebaseConfig`.

## 2) أسرار GitHub

في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**

| الاسم | القيمة | إلزامي |
|---|---|---|
| `GOOGLE_SERVICES_JSON` | محتوى ملف `google-services.json` كاملاً | ✅ |
| `FIREBASE_WEB_CONFIG` | كائن الويب بصيغة JSON، مثل `{"apiKey":"…","authDomain":"…","projectId":"…","appId":"…"}` | مستحسن |
| `FIREBASE_SERVICE_ACCOUNT` | مفتاح حساب خدمة (JSON) لنشر لوحة الويب والقواعد تلقائياً على Firebase Hosting | اختياري |

> بدون `FIREBASE_WEB_CONFIG` يحاول البناء استخراج الإعدادات من `google-services.json`. وإن لم تعمل، تطلب اللوحة لصق الإعدادات عند أول فتح.

## 3) البناء

كل `push` على `main` يشغّل **Actions ← Build** ويُنتج:

- `FamilyGuard-Child.apk` — لأجهزة الأطفال.
- `FamilyGuard-Parent.apk` — للمالك.
- `ZemoryGuard-Windows.zip` — لأجهزة ويندوز.

تجدهما في **Releases ← latest** وفي Artifacts الخاصة بكل تشغيل.
لإصدار مرقّم: `git tag v1.0.0 && git push --tags`.

مع `FIREBASE_SERVICE_ACCOUNT` تُنشر اللوحة على `https://<project-id>.web.app` ومعها ملف التحديث
`/apk/FamilyGuard-Child.apk`، وتُنشر قواعد Firestore تلقائياً.
(للحصول على المفتاح: Google Cloud Console ← IAM ← Service accounts ← حساب بصلاحيتي *Firebase Hosting Admin* و *Firebase Rules Admin* ← Keys ← Add key ← JSON.)

## 4) إعداد جهاز طفل (بدون كمبيوتر)

1. في تطبيق الوالد: **إضافة جهاز** ← اكتب اسم الجهاز وبريداً وكلمة مرور خاصين به (البريد لا يحتاج أن يكون حقيقياً، مثل `ahmed.phone@family.dz`).
2. أرسل `FamilyGuard-Child.apk` إلى جهاز الطفل (واتساب، تيليغرام…) وثبّته.
3. افتحه واكتب بريد الجهاز وكلمة مروره ← **ربط الجهاز**.
4. اتبع **خطوات الإعداد** التي تظهر حتى «✅ الحماية مكتملة».
   - أندرويد 13+: إذا كانت «إمكانية الوصول» رمادية ← معلومات التطبيق ← ⋮ ← «السماح بالإعدادات المقيّدة».
5. من تطبيق الوالد ← الجهاز ← **القيود والإعدادات**: عيّن **رمز المالك** (يقفل الإعدادات وتطبيق الحماية على جهاز الطفل).

كل جهاز له حساب منفصل: يستطيع فقط إرسال تقاريره وقراءة أوامره، ولا يستطيع تغيير القواعد.
يتطلب ذلك نشر ملف `firestore.rules` الحالي في Firebase.

### حماية كاملة (اختياري، عبر الكمبيوتر)
لمنع إعادة ضبط المصنع والوضع الآمن وتغيير الوقت نهائياً، اجعل التطبيق «مالك الجهاز» (مرة واحدة، بعد الربط):
1. احذف حسابات Google مؤقتاً، وفعّل خيارات المطوّر و«تصحيح USB».
2. `scripts/setup-device.bat FamilyGuard-Child.apk` (أو `.sh`).
3. أعد إضافة الحسابات.

**للتلفاز:** `./scripts/setup-device.sh FamilyGuard-Child.apk 192.168.1.50` (عنوان IP التلفاز).

## 4ب) كمبيوتر ويندوز

1. في تطبيق المالك: **إضافة جهاز** ← النوع **🖥️ كمبيوتر ويندوز** ← بريد وكلمة مرور للجهاز.
2. على الكمبيوتر: يجب أن يستعمل الطفل **حساب ويندوز عادياً (ليس مسؤولاً)**.
3. من حساب المسؤول: نزّل `ZemoryGuard-Windows.zip` من صفحة الإصدارات، فك الضغط،
   ثم كليك يمين على `install.bat` ← **تشغيل كمسؤول**، واكتب بريد الجهاز وكلمة مروره واسم حساب الطفل.
4. تعمل الحماية كخدمة ويندوز لا يستطيع الحساب العادي إيقافها.

| الميزة على ويندوز | كيف |
|---|---|
| وقت الاستخدام والحد اليومي لكل برنامج | تتبّع النافذة الأمامية في جلسة الطفل، وإغلاق البرنامج عند انتهاء الوقت |
| حظر / قفل برمز المالك | يُغلق البرنامج وتظهر رسالة فيها خانة رمز المالك |
| وقت النوم / إيقاف الكل | قفل الشاشة كل 30 ثانية وإغلاق البرامج |
| جدول الشاشة | خارج وقت اليوم: قفل الشاشة كل 30 ثانية، أو إغلاق كل البرامج ما عدا المسموحة |
| طلب فتح برنامج | زر «اطلب من المالك» في نافذة المنع ← يصل الطلب إلى تبويب «طلبات الطفل» |
| المواقع | سياسات Chrome / Edge / Brave / Firefox + ملف hosts، سجل كامل بالروابط، وضع المواقع المسموحة فقط، البحث الآمن |
| طلب موقع | أيقونة الدرع بجانب الساعة ← «طلب السماح بموقع» |
| القيود | مدير المهام، الإعدادات، regedit، cmd، Win+R، المتجر، MSI، فلاشات USB |
| الأوامر | قفل الشاشة، إعادة التشغيل، تثبيت MSI/EXE، حذف البرامج التي تدعم الحذف الصامت |

للإزالة: `uninstall.bat` كمسؤول.

## 5) الاستخدام

افتح تطبيق الوالد أو لوحة الويب، وسجّل الدخول (أو أنشئ الحساب من نفس الشاشة أول مرة):

- **التطبيقات**: الاستخدام اليومي، حد يومي، حظر، قفل برمز، إخفاء، حذف.
- **الوقت**: استخدام اليوم، وقت النوم، إيقاف الكل، التطبيقات المسموحة دائماً.
- **الشاشة**: جدول أسبوعي (من – إلى لكل يوم) وما يحدث بعد انتهاء الوقت: قفل كامل أو تطبيقات مسموحة فقط.
- **طلبات الطفل**: طلبات فتح المواقع والتطبيقات، مع سماح مؤقت أو دائم أو رفض.
- **المواقع**: تشغيل التسجيل والحظر والبحث الآمن، قوائم جاهزة، وسجل كل يوم مع زر حظر لكل نطاق.
- **القيود والإعدادات**: رمز المالك وقيود الجهاز.
- **تثبيت وأوامر**: تثبيت APK من رابط، تحديث تطبيق الجهاز، قفل الشاشة، إعادة التشغيل، مزامنة.

على جهاز الطفل، تطبيق Zemory Family Guard محمي برمز المالك ويعرض حالة الصلاحيات، ويسمح بـ«إيقاف مؤقت 30 دقيقة»
و«إزالة الحماية» (ترفع كل القيود وتلغي وضع مالك الجهاز، فيمكن بعدها حذف التطبيق).

## ملاحظات مهمة

- **iPhone/iPad و تلفازات Samsung (Tizen) و LG (webOS)** غير مدعومة: هذه الأنظمة لا تسمح بتطبيقات تحكم من هذا النوع.
- **مفتاح التوقيع** (مرة واحدة، قبل تثبيت التطبيق على الأجهزة):
  1. أنشئ سرّاً باسم `SIGNING_PASSWORD` وضع فيه كلمة مرور من اختيارك (6 أحرف على الأقل) واحتفظ بها.
  2. Actions ← **Create signing key** ← **Run workflow**.
  3. بعد انتهائه نزّل الـ Artifact المسمّى `signing-key`، وانسخ محتوى `keystore-base64.txt` إلى سرّ جديد باسم `SIGNING_KEYSTORE_BASE64`، واحتفظ بنسخة من `release.jks` في مكان آمن.
  لا تغيّر المفتاح بعد تثبيت التطبيق على الأجهزة، وإلا لن يقبل الجهاز التحديث.
- **رابط التحديث** يجب أن يكون عاماً: روابط Releases لا تعمل إذا كان المستودع خاصاً — استخدم Firebase Hosting (`FIREBASE_SERVICE_ACCOUNT`).
- **سجل المواقع**: يعمل عبر VPN محلي يمرّ منه DNS فقط (لا يبطئ الإنترنت ولا يرسل البيانات لأي خادم خارجي).
  يُعطَّل «DNS عبر HTTPS» في Chrome/Edge تلقائياً حتى يعمل الفلتر.
- **حدود Firestore المجانية**: 20 ألف كتابة/يوم، يستهلك كل جهاز تقريباً 1000 فقط.
- **الشفافية**: يُستحسن إخبار الأطفال بوجود المراقبة وبالقواعد المتفق عليها.

- **نشاط داخل التطبيقات (أندرويد)**: من تبويب التقارير تختار تطبيقاً مثل فيسبوك فيُسجَّل تقريبياً عنوان الصفحات/المجموعات/الحسابات ونص البحث (لا محادثات ولا كلمات مرور).


## تطبيق الوالد على ويندوز

`ZemoryParent-Windows.zip` (من صفحة الإصدار `latest`): فك الضغط كاملاً (يجب أن يبقى مجلد `web` بجانب `ZemoryParent.exe`) ثم شغّل `ZemoryParent.exe`.
- يستخدم **نفس حساب** تطبيق الوالد على أندرويد (البريد وكلمة المرور نفسهما)، ويعرض اللوحة نفسها.
- عند إغلاق النافذة يبقى في شريط المهام (قرب الساعة) ويُظهر إشعارات ويندوز لطلبات الأطفال.
- من أيقونته في الشريط: «تشغيل مع ويندوز» و«إغلاق نهائي».
- يحتاج مكوّن WebView2 (موجود في ويندوز 11 وأغلب أجهزة ويندوز 10).
